# Optional Semantic References — Open Edition

**Catalog version:** 1.0  
**Applies to:** AUREN Core Skill 1.1.x — Open Edition

## Purpose

The AUREN Core Skill Open Edition is fully functional without external proprietary models or framework pages. This document defines a narrow optional semantic-extension layer for expressly published external references.

The machine-readable catalog is `OPTIONAL-SEMANTIC-REFERENCES.json`.

## Binding boundaries

- External references are **optional** and **not required for core operation**.
- They are **not bundled** into the skill.
- Their presence does **not** make them CC BY-SA merely because the Open Edition links to them.
- They may **never override** the embedded AUREN Core Specs, safety, crisis/referral logic, privacy rules, or human-responsibility constraints.
- Ordinary Runtime use does **not** automatically fetch these references.
- A host may consult a canonical reference when the user explicitly requests the named model/framework, or when the named reference is clearly relevant and materially improves orientation.
- If a reference is unavailable, continue with the Open Core and state the limitation when material.
- Do not crawl linked pages, infer unpublished steps, reconstruct a complete proprietary methodology from public traces, or claim completeness beyond the expressly published source.
- Do not cache or repackage proprietary page content as if it were part of the Open Edition.
